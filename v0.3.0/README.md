# SIMFLOW — Maya 2025 シミュレーションアサインツール（v0.3.0）

選択したアニメーションコントローラーに Spring / Gravity / Pendulum のシミュレーションを割り当て、
Proxy でプレビューしたうえで、検証付きで Animation Layer にベイクするツールです。リグの階層や接続は変更しません。

## インストールと起動

### リリース版

`D:/OG_Tools/SIM/release/` に、バージョンごとのフォルダ（`v0.3.0` など）があります。
使うバージョンのフォルダの `install_simflow.py` を、下の手順でドロップしてください。
別のバージョンに切り替えるときは、そのフォルダの `install_simflow.py` をドロップして「再インストール」を選びます。
テスト用のシーンは `release/test_scenes/` にあります（中身は `説明.txt`）。

リリースの作り方（Maya は不要、`D:/OG_Tools/SIM` で実行）：

* `python make_release.py` … `release/v<バージョン>/` を作ります。バージョンは `simflow/__init__.py` の `__version__` です。
  同じバージョンのフォルダがあるときは止まります（`--force` で作り直し）。新しいリリースは先に `__version__` を上げてください。
  中身は `install_simflow.py`・`simflow/`（tests と __pycache__ を除く）・`README.md`・`リリース情報.txt`。
* `python make_release.py --scenes` … mayapy で `release/test_scenes/` のシーンを作り直します（`make_test_scene.py` の内容）。

### ドラッグ＆ドロップでインストール（おすすめ）

1. `D:/OG_Tools/SIM/install_simflow.py` を、Maya 2025 のビューポートにドラッグ＆ドロップします。
2. 次のことが自動で行われます。
   * Maya のモジュールファイル `<ユーザーの Maya フォルダ>/modules/simflow.mod` を作ります。
     これで、Maya を再起動しても SIMFLOW を読み込めます。ドッキングした SIMFLOW パネルも、起動時に元の場所に戻ります。
   * 今開いているシェルフに **SIMFLOW** ボタン（黄色いアイコン）を追加します。
     ボタンを右クリックして **読み込み直して起動** を選ぶと、SIMFLOW を更新したあとで、Maya を再起動せずに読み込み直せます。
   * SIMFLOW を開きます。
3. 次からは、シェルフのボタンで開きます。

* ファイルはコピーしません。`install_simflow.py` があるフォルダ（`simflow` フォルダの隣）を、そのまま使います。
  フォルダを移動したときは、移動先の `install_simflow.py` をもう一度ドロップしてください。
* インストール済みのときにドロップすると、**再インストール / アンインストール / キャンセル** を選べます。
  アンインストールでは、モジュールファイルとシェルフのボタンを削除します。SIMFLOW のファイルは削除しません。

## 基本の流れ

SIMFLOW では、髪・尻尾・アクセサリーなど、揺れるものを 1 つずつ **揺れもの** として登録し、揺れものごとに値を調整します。

1. 揺れるコントローラーを根元から先端の順に選択し、**＋ 新規** を押します。揺れものができ、選択したコントローラーが登録されます。
   **名前変更** で「髪」などの名前を付けておくと分かりやすくなります。ほかの揺れものも同じように作ります。
2. 一覧で揺れものを選ぶと、その揺れものの設定が下に出ます。
   * **揺れ方**：**つながって揺れる**（髪・尻尾など。リストの上が根元）か **1 つずつ**（左右の耳飾りなど、それぞれ独立）
   * **コントローラー**：**選択を追加** / **外す** / **▲ ▼**（並べ替え）
   * **プリセット**、**硬さ**・**減衰**・**重さ**・**追従性**・**適用率**・**重力**
   * そのほかの項目（初期状態、初速度、重力の方向、振り子の長さ、先端の軸、回転・移動の軸、戻る姿勢）は **詳細** に折りたたんであります。
3. **範囲** でフレーム範囲とプリロールを決めます。出力先やレイヤー名は **ベイクの詳細** にあります。
4. **計算 / プレビュー** を押します。チェックの入った揺れものがまとめて計算され、`SIMFLOW_ROOT` の下にプロキシができます
   （灰色 = 元のアニメーション、黄色 = シミュレーション結果）。タイムラインをスクラブして確認します。
5. **ベイク** を押します。チェックの入った揺れものを元のアニメーションから計算し直してベイクし、検証結果をダイアログに表示します。
6. **元に戻す** は、一覧で選んでいる揺れものからベイクを取り除きます。全部戻すときは **メニュー → すべての揺れものを元に戻す**、
   不要になったノードは **メニュー → クリーンアップ** で削除します。

* 値を変えても、**計算 / プレビュー** を押すまでプロキシは前の結果のままです。まだ反映していない変更があるときは、ボタンが
  **計算 / プレビュー（未反映の変更あり）** になります。
* プリセットの横の **…** → **初期値に戻す** で、その揺れものの値をすべて（詳細の項目も含めて）初期値に戻せます。
  プリセットや詳細で変えた値は、見えているスライダーを戻しても残るので、最初からやり直すときに使ってください。
* **重力** はぶら下がるもの（髪など）にとって「下向きへ戻す力」になるので、オンにすると揺れが速く小さくなります（物理的に正しい動きです）。
  重力をオンにしても同じくらい揺らしたい場合は、硬さを下げてください。上向きのもの（アンテナなど）は、重力で倒れようとします。
* 一覧のチェックを外した揺れものは、計算とベイクの対象から外れます（設定は残ります）。
* 1 つのコントローラーは、1 つの揺れものにしか登録できません。
* 揺れもの同士が親子関係にあっても構いません（たとえば「頭」の下に「髪」）。親側の揺れの結果に乗せて、子側を計算します。
* 「つながって揺れる」でコントローラーが 1 つだけの場合は、1 つずつと同じ扱いになります。
* 揺れものの一覧と設定は、シーンに保存されます。Phase 2 で保存したシーンは「揺れもの 1」として読み込みます
  （以前のコントローラーごとの個別設定は使わなくなりました。値を変えたい場合は、別の揺れものに分けてください）。

### つながって揺れる（チェーン）

**長さと向きはコントローラーの位置から自動で決める**（詳細、既定でオン）だと、各段の長さと向きを、次のコントローラーの支点までの距離と方向から決めます。最後のコントローラーは、一つ前と同じ長さで同じ方向に伸ばします。

チェーンは、並べたコントローラー全体を 1 本のつながった棒として、まとめて解きます（連成の解法）。
各関節のばねとダンパーは親と子の両方に逆向きに働くので、子の重さや揺れが親を引き戻します。
どの関節も同じ硬さになり、均一な棒と同じように根元がいちばん曲がって、先端は素直についていきます。
硬さの値は「チェーン全体を根元で 1 本の棒として振ったときの固有振動数」を表します（段数が変わっても意味は同じです）。

* **骨が何本も並ぶもの（袖・スカートなど）は、1 つの揺れものにまとめて登録できます。** 登録したコントローラーの階層から、
  骨ごとに別のチェーンに自動で分けます（揺れものの一覧に「チェーン 3 本・9 個」のように出ます）。
  各コントローラーは、登録したコントローラーのうち一番近い親にぶら下がります。途中で枝分かれしているときは、一覧で先にあるほうがチェーンを続け、
  ほかの枝は分かれ目から始まる別のチェーンになります（分かれ目の揺れに付いて動きます）。
  階層があるときはチェーンの順番も階層で決まるので、一覧の並び順は関係ありません。
* 既定では、骨どうしはつながっていません。同じ値・同じ親の動きでも、肩から遠い骨ほど大きく振られるなど、骨ごとの位置の違いの分だけずれ、
  間が広がることがあります。布でつながっているものは **横のつながり** を上げます（下記）。ばらつかせたいときは「ばらつき」を上げます（下記）。
* 親子関係のないコントローラーだけを並べた場合は、一覧の順に、前のコントローラーにつながっているものとして計算します（回転だけを出力します）。
* チェーンでは移動のシミュレーションは使えません（「移動」の軸をオンにすると警告します）。移動も揺らしたい場合は「1 つずつ」を使ってください。
* 各段の軸まわりのねじれは、アニメーションに従います（重力や慣性でねじれることはありません）。
* 「追従性」は近似です（各関節の目標の動きに、指定の割合だけ乗せます）。

### 値の意味

画面右上の **？ 値の説明** で、各値の説明と調整のこつを表示します（スライダーの名前にマウスを乗せても同じ説明が出ます）。

| 値 | 意味 | 目安 |
|---|---|---|
| 硬さ | 元の形に戻ろうとする強さ。上げると速く小さく、下げるとゆっくり大きく揺れる | 0 = 戻ろうとしない（重力だけで垂れる）、50 = 1 秒に約 1 往復、100 = 約 10 往復 |
| 減衰 | 揺れの収まりやすさ | 0 = いつまでも揺れる、10〜20 よく揺れる、30 標準、50 以上 ねばって止まる、100 = 揺れ戻らない |
| 重さ | 重いほどゆっくり大きく揺れ、重力で深く垂れる（硬さとは逆向きに効く） | 50 = 標準 |
| 追従性 | アニメーションの動きに遅れずに付いていく割合 | 0 = 慣性で遅れて振られる（ふつう）、100 = 遅れない（重力だけ効く） |
| 空気抵抗 | 空間に対する動きにかかるブレーキ（減衰はアニメーションとの差にかかる）。振り上げた先端が頂点でふわっと留まり、ゆっくり下りる | 0 = なし。重力を下げると「たまる」感じが強くなる。上げすぎると全体が重たく遅れる |
| 横のつながり | 1 つの揺れものに並んだ骨（袖・スカート）を布のようにつなぎ、隣の骨とポーズのときより離れないようにする | 0 = つながない、100 = 広がらない |
| 適用率 | 最後に元のアニメーションと揺れの結果を混ぜる割合。揺れ方は変えずに量だけ減らす | 100 = 結果そのまま、50 = 半分、0 = 元のまま |
| 当たり判定 / 太さ | 「当たり判定」欄の球・カプセルに、各段の先端がめり込まないようにする。太さ = 表面からこの距離の手前で止める | 太さ 0.5 cm（髪の束の太さに合わせる） |
| 押し出す揺れもの | 選んだ揺れものの骨に食い込まないようにする（片方向） | なし |
| 重力 | 下に垂れる。ぶら下がるものには「下へ戻す力」になり、揺れが少し速く小さくなる | 100 = 1 G |

### 柔らかい髪・根元からストンと垂れるもの

* **柔らかい髪**：プリセット **髪**（硬さ 10、減衰 15、重さ 40、重力あり）。根元の動きが波のように先端へ伝わります。
  もっと柔らかくするなら硬さを下げ、揺れが長く続くなら減衰を上げます。
* **根元からストンと下に垂れるもの**（髪、着物の袖など）：プリセット **垂れる（髪・袖）**（硬さ 0、減衰 20、重力あり、
  初期状態「落ち着かせてから開始」）。元の形に戻ろうとする力がないので、モデルの形に関係なく、1 フレーム目から根元の真下に垂れ、
  根元の動きに合わせて揺れます。少しだけ元の形を残したいときは、硬さを 5〜10 にしてください。
* 重力をオンにするときは、初期状態を「落ち着かせてから開始」にすると、開始直後に落下しません（重力ありのプリセットは自動でそうなります）。

### 振り上げた先端を上でためる（ふわっと）

**空気抵抗** を上げ、**重力** を下げます（プリセット **ふわっと（軽い髪）**：硬さ 10、減衰 10、重さ 40、空気抵抗 70、重力 50）。
6 段の髪の根元を横に 20 cm 振って止めたとき、先端が頂点の半分より上にいる時間は、次のように伸びました。

| 重力 | 空気抵抗 0 | 空気抵抗 100 |
|---|---|---|
| 100 | 0.12 秒 | 0.79 秒 |
| 50 | 0.12 秒 | 1.54 秒 |

* 空気抵抗は振り上げる勢いも少し弱めます（振り上がり 10 cm → 8 cm）。
* 制約：真下に垂れた髪を **真上に** 動かしても、先端は持ち上がりません。SIMFLOW のチェーンは伸び縮みしない棒の連なりなので、
  鎖の向きと一直線の力では曲がりません（本物の髪は真上に押されるとたわみます）。横や斜めに振る動きでは振り上がります。

### ばらつき

同じ揺れものの中で、骨（チェーン）ごとに **硬さ・減衰・重力** を少しずつ変えて、揺れのタイミングや止まり方をずらします
（100 で 硬さ ±15、減衰 ±10、重力 ±25%）。「1 つずつ」のときは、コントローラーごとに変えます。

* 1 本の骨の中の段は、同じ値です。どの骨がどちらにずれるかは、骨の根元のコントローラーの名前と「詳細」の **ばらつきの型** の番号で決まります。
  計算し直しても、シーンを開き直しても、同じ結果になります。番号を変えると、ずれ方が入れ替わります。
* 名前空間は無視します（同じリグを別の名前空間で読み込んでも、同じばらつき方になります）。
* 0〜100 の外に出る値は、端で折り返します（硬さ 0 の「垂れる」でも、骨ごとに違う値になります）。
* 確認用の袖（腕が 40 度回る、骨 3 本 × 3 段）で、骨どうしの向きの差の最大を測りました。
  - 「垂れる」：ばらつき 0 で 9〜20 度、100 で 17〜29 度。
  - 「髪」：ばらつき 0 で 9〜18 度、100 で 21〜34 度。
  - 「ソフト」（重力なし）は効きが強く、100 だと先端の振れ幅が 63〜161 度まで開きます。この場合は 20〜40 くらいから試してください。

### 横のつながり（袖・スカート）

**太い束のコントローラーに細い束がぶら下がるリグ**（ポニーテールなど）も、まとめて 1 つの揺れものに登録できます。
分かれ目では、下に多くのコントローラーがつながる方（太い束）を 1 本のチェーンとして続け、細い束はその結果に乗って揺れます。
横のつながりは、細い束どうし（太い束の同じところから分かれた束も、別のところから分かれた束も）をつなぎます。
頭が激しく動くショットで振り回されすぎるときは、硬さを上げて重力をオンにします（利用者のポニーテールでは、硬さ 75・重力オンで
アニメーションからのずれが最大 49°。硬さ 50・重力オフでは 180° 近く裏返った）。

着物の袖のように、並んだ骨（チェーン）が布でつながっているときに使います。
**横のつながり** を上げると、隣の骨の同じ段の先端どうしが、ポーズのとき（アニメーションの姿勢）の間隔より離れないようにします。

* 0 = つながない（これまでどおり）、100 = ポーズのときの間隔より広がらない。間の値では、広がりを途中まで抑えます。
* 近づく方向（布がたるむ・重なる）は止めません。引き戻した勢いで内側へ跳ね返ることもありません。
* 隣の骨は、骨の根元の位置から自動で決めます。いちばん近い骨と、反対側にあるほぼ同じ距離の骨につなぎます
  （袖のように並んだ骨は端から順に、スカートのように輪に並んだ骨は輪につながります）。
* つないだ骨は、同じ細かさ（内部ステップ）で一緒に計算します。0 のときは、1 本ずつ計算したときと同じ結果です（細かさが同じ場合）。
* 枝分かれから始まる骨（別の骨の途中にぶら下がる骨）は、その骨に付いて動くため、つなぎません。
* つないだ骨は、根元の骨（一覧で最初の骨）で見つけたワープを全部の骨に使います（ワープ吸収がオンのとき）。
* 「つながって揺れる」で、骨が 2 本以上あるときに使えます。設定はシーンに保存されます。プリセットには含みません（リグの作りで決まる値のため）。
* 当たり判定とつながりの両方が効くときは、当たりを優先します（引き戻したあとで、もう一度当たりから押し出します）。

確認用の袖（E、間隔 2 cm の骨 3 本 × 3 段）で、隣の骨の段が、ポーズのときより最大で何 cm 離れたかを測りました。

| プリセット | つながり 0 | 25 | 50 | 100 |
|---|---|---|---|---|
| 髪 | 1.65 | 0.81 | 0.43 | 0.02 |
| 垂れる | 1.43 | 0.75 | 0.41 | 0.01 |
| ソフト | 5.84 | 1.35 | 0.71 | 0.13 |

揺れの大きさはほぼ変わりません（ソフトは、骨ごとにばらばらに振れていた分がそろうので、先端の最大の振れが 79° → 65° になります）。

### 横揺れ抑え

**末端（先端）が前後左右（世界の水平方向）に動くのを抑え、上下の動き（ジャンプの着地のはねなど）を残します。** ジャンプや激しいアクションで、ポニーテールが暴れるときに使います。

- 比べるのは、そのフレームのアニメーションの姿勢です。首の傾きなども含めた元の位置からの水平のずれを抑えます（決まった姿勢には引っぱりません）。
- チェーンでは末端の位置で判定し、戻す量を根元から先端までの段で分け合います（その軸に沿って末端を動かせる長さの割合）。途中の段は曲がれます。
  水平の 2 つの軸について順に戻します。速さは、各段が自分で水平に回る速さのごく一部（強さ × 5 %）だけ減らします
  （各段の水平の回る速さを全部消すと、途中で曲がって末端が上下する動きまで止まった：4 段・100 で上下 23 → 0.1 cm）。
- 0 = 抑えない、50 = 水平のずれが減る、75〜90 = ほとんど水平に動かない（上下は残る）。
- 100 = 末端は水平にはまったく動かない。骨は根元を中心に回るので、斜めに伸びた骨が上下に動くと末端は必ず前後にも動きます。
  そのため 100 では上下の動きもほとんどなくなります（残るのは途中で曲がる分だけ）。
- 1 本だけ（1 つずつ）の骨は途中で曲がれないので、100 では止まります（75 では上下が残る）。
- 太い束からぶら下がる細い束は、太い束の計算結果に運ばれた後ではなく、シーンのアニメーションの位置と比べます。
- 計算の前に重力で落ち着かせる（開始状態「落ち着いた姿勢」）ときも効きます。
- 縄・ひもでは使いません。

斜め後ろに伸びたチェーン（ジャンプ + 横揺れ、硬さ 40）での末端のずれ：

| 横揺れ抑え | 4 段：水平 / 上下 | 8 段：水平 / 上下 |
|---|---|---|
| 0 | 24.8 / 23.2 cm | 47.3 / 43.7 cm |
| 50 | 17.6 / 24.1 cm | 26.5 / 42.8 cm |
| 75 | 6.7 / 22.9 cm | 10.6 / 38.9 cm |
| 90 | 3.6 / 20.3 cm | 4.0 / 23.5 cm |
| 100 | 0.1 / 0.6 cm | 0.1 / 0.5 cm |

### 形を保つ（チェーン）

**重力でカールや形が垂れないようにします。** コントローラーどうしの間の関節を、重力では曲がらないようにします。

- 各関節は、その先にぶら下がる部分の重さを「今の姿勢で」支えます。関節のばねが、そのフレームのアニメーションの形（首の傾きなども含む）に保ちます。
- チェーンの根元は今までどおり全体の重さを受けます。根元からは垂れ・揺れ、ジャンプでは浮いて落ちます。根元を垂れにくくするには、硬さカーブの根元側を上げてください。
- 太い束からぶら下がる細い束は、ぶら下がる角度（細い束の根元の関節）も重力で変わりません。
- 頭の動きによる揺れはそのまま残ります。重力で関節が引き戻されなくなる分、揺れは少し大きくなります（重力オフのときに近い揺れ方）。
- 0 = 今までどおり、100 = 間の関節は重力で曲がらない。重力オフでは何も変わりません。計算時間は変わりません。
- 揺れ方が「チェーン」のときだけ使えます。

利用者のポニーテール（54 個、硬さ 50・重力オン）での、段ごとのアニメーションからのずれ（平均のずれ = 垂れたままのずれ、揺れ = 平均からの rms）：

| 形を保つ | 平均のずれ（中央値 / 最大） | 揺れ（中央値 / 最大） |
|---|---|---|
| 0 | 4.6° / 30.2° | 10.1° / 39.7° |
| 50 | 3.3° / 25.7° | 11.5° / 46.8° |
| 100 | 5.0° / 15.2° | 13.7° / 54.1° |

（残る平均のずれは、頭の動きによる片寄りです。重力オフでも 3.5° / 17.9°。）

試してやめた方法：関節を硬くする（揺れが硬くなった）、アニメーションの姿勢で重さを支える（持ち上げたカールがひっくり返った）、
後から垂れを引く「影のチェーン」（揺れは変わらないが、利用者が動きがよくないと判断）。

### カメラ合わせ（ワープ吸収）

カメラに合わせて、キャラを **1 フレームで大きく動かした（ワープさせた）** ところでは、画面ではほとんど動いていなくても、
ワールドで計算した揺れものが大きく暴れます。設定の **カメラ合わせ（ワープ吸収）** 欄で、これを防げます。

* **1 フレームで大きく動かしたところ（ワープ）を吸収する** にチェックを入れると、ワープを見つけて、その分の動きでは揺らしません。
  揺れものはキャラと一緒にワープし、それまでの揺れはそのまま続きます（止まったり、リセットされたりしません）。
* 見つけ方：前後のフレームの動きから飛び出している移動と向きの変化を、ワープとみなします。
  * 走りのような一定の速さの動きや、動き出し（ダッシュ）は、ワープとみなさず、ふつうに揺れます。
  * **ワープの移動**（既定 10 cm）、**ワープの向き**（既定 25°）より小さい飛びは、ワープとみなしません。
  * **フレーム数**：数フレームかけて位置を直している場合は 2〜3 にします。
  * 向きは、重力の軸まわりの回転（キャラの向きを変えること）だけを吸収します。傾きのワープは吸収しません（重力の向きが変わらないようにするため）。
* **カメラ**（任意）：ショットのカメラを選ぶと、画面ではっきり見えている飛び（**画面の境目**、既定は画面の横幅の 5% より大きいもの）は、
  演技（殴る、飛びのくなど）とみなして吸収しません。カメラとキャラを一緒にワープさせた場合や、カメラの方へ寄せた場合は、画面ではほとんど動かないので吸収します。
* **ワープにする / ワープにしない**：自動でうまく拾えないときは、フレームを書きます（例：`37, 52, 60-62`）。
  フレームは、キャラが新しい位置に来た最初のフレームです。「ワープにする」に書いたフレームは、カメラで見えていても吸収します。
* 計算のあと、欄のいちばん下に、吸収したフレームと、見えている動きとして吸収しなかったフレームを表示します。
* **吸収の強さ**：100 = ワープの分の揺れを全部なくす、50 = 半分残す。
* 「つながって揺れる」では、根元のコントローラーの動きで見つけて、骨全体に同じように効かせます。
  「1 つずつ」では、コントローラーごとに見つけます（2 段目より先は親の揺れも含めて見るので、見積もりがごくわずかにずれます。確認用のシーンで 0.06° 以内）。
* 設定はシーンに保存されます。プリセットには含みません（ショットごとの設定のため）。

確認用のシーンの F（ポニーテールとショットのカメラ `shotCam_F`）に、24F・40F・56F のカメラ合わせのワープと、72F の画面で見える速い動きが入っています。
ワープ吸収なしでは 24F のあと先端が最大 170° 暴れ、ありでは 6° 以内（ワープの前と同じくらい）に収まります。72F はふつうに揺れます（22°）。

### ベイク前にリグで確認する（リグで見る）

「計算 / プレビュー」の下の **リグで見る（ベイク前に実際に動かす）** にチェックを入れて「計算 / プレビュー」を押すと、計算結果が実際のコントローラーに当たり、メッシュも一緒に動きます。
チェックを入れただけでは計算しません（ボタンが「未反映の変更あり」になります）。

* 結果は SIMFLOW 専用の一時的なオーバーライドレイヤー `SIMFLOW_Preview` に入ります。
  元のカーブやリグの接続は変えません（コンストレイントを使わないのは、アニメーションの付いたチャンネルに pairBlend が挿入され、リグの接続が変わるためです）。
* 範囲の外のフレームは、元のアニメーションのままです。
* 値を変えて「計算 / プレビュー」を押すと、リグも更新されます。計算は常に元のアニメーションから行います（このレイヤーは計算中はミュートします）。
* 外すとき：チェックを外す、「プレビューを消す」、または Ctrl+Z。**ベイクすると自動で外れます**（ベイクの結果が同じ動きを表示します）。
* ロック、コンストレイント、エクスプレッションなどで動かせないチャンネルは飛ばして、ステータスに表示します（プロキシでは確認できます）。

### 当たり判定（コリジョン）

髪や袖が頭・体にめり込まないように、**球** と **カプセル** の当たりを置けます。

1. Maya で頭のジョイントやコントローラーを選び、「当たり判定」欄の **＋ 球**（首・肩・腕・胴なら **＋ カプセル**）を押します。
   選んだノードに付いて動く当たりができ、Maya 上で選択された状態になります（何も選んでいなければ、ワールドに置きます）。
2. 位置と向きは、ふつうの移動・回転で合わせます。大きさはチャンネルボックスの **半径**、カプセルは **長さ**（ローカル Y 軸方向）も変えます。
3. 揺れものの設定の **当たり判定**（既定でオン）と **太さ**（当たりの表面から、この距離の手前で止める）を確認して、計算します。

* 判定するのは各段の先端（コントローラーの間）です。根元（生え際）は押し出さないので、髪の根元が頭の球の内側にあっても、髪が浮くことはありません。
* **開始フレームで当たりの中にめり込んでいるとき**は、計算の前に外へ出してから始めます。チェーンは、押し出した段から先を形を保ったまま回して出し、
  重力なしで当たりに寄りかかった形に落ち着かせてから（アニメーションの初速はそのまま）始めます。1 つずつの揺れものは、開始フレームから外へ出します。
  以前は開始フレームがめり込んだまま出力され、次のフレームで一気に飛び出していました（中ほどが 3 cm めり込んだ 6 段の髪で、先端が 1 フレームに 硬さ 75 で 14.6 cm、
  90 で 17.5 cm 動いた → 0.15 / 0.27 cm）。
  段の間隔より小さい当たりは、段と段の間をすり抜けることがあります。
* 当たったときは、表面に沿って滑ります（めり込む向きの勢いだけを消します）。
* 当たりは SIMFLOW のノード（`SIMFLOW_COLLIDERS` の下）で、リグには触りません。付いて動くのは、付けたノードの **元のアニメーション** です
  （付けたノード自体を SIMFLOW で揺らしていても、当たりはその揺れには付いていきません）。
* 当たりは **クリーンアップでは消えません**。消すときは一覧で選んで **当たりを削除** を押します。一覧をダブルクリックすると Maya 上で選択します。
* 当たりを動かしたり大きさを変えたりすると、計算ボタンが「未反映の変更あり」になります。
* 当たりのノードを非一様にスケールした場合、半径は軸の平均で近似します（大きさは「半径」「長さ」で変えてください）。

### 縄・ひも（両端を持つ、縄跳びなど）

縄跳びの縄のように **両端を手に持つもの** は、揺れ方 **縄・ひも（両端を持つ）** で揺らします。
スプライン IK の縄で、縄の途中にコントローラーが横並び（親子ではない）になっていて、両端の持ち手が手にコンストレインされているリグを想定しています。

1. 持ち手 → 縄のコントローラー（縄に沿った順）→ 反対の持ち手 の順に選んで **＋ 新規**（または「選択を追加」）を押し、揺れ方を **縄・ひも（両端を持つ）** にします。
   リストの **いちばん上と下が持ち手** です（リストに「持ち手」と出ます）。
   **選んだ順番に関係なく、SIMFLOW が縄に沿った順に並べ直します**（揺れ方を縄にしたときと計算のとき。並びはスクリプトエディタに出ます）：
   * 縄のコントローラーが持ち手の子のリグ：持ち手 = ほかのコントローラーの親の 2 つ。それぞれの子を、持ち手から近い順に。
   * 縄のコントローラーが持ち手に付いて動くリグ（持ち手の動きを混ぜて付いていくグループの下など）：計算範囲の動きから、
     片方の持ち手とまったく同じに動くものがその持ち手の隣、両方の中間の動きのものが真ん中、の順に（持ち手はリストのいちばん上と下）。
   * どちらでもないリグ：リストの順のまま使うので、▲▼ で縄に沿った順に直してください（縄に沿っていないと、スクリプトエディタに警告を出します）。
   順番がばらばらだと、遠いコントローラーどうしをつないでしまい、縄が散らばります。
2. 床に当てるときは、床のノード（床のメッシュやロケーター）を選んで「当たり判定」欄の **＋ 床** を押します。
3. 重力をオンにして計算します。プリセットの **縄跳びの縄** / **縄跳びの縄（キーに合わせる）** を適用すると、縄跳び向けの値がまとめて入ります（下の表）。
   プリセットは値だけを入れるので、揺れ方（縄・ひも）は先に切り替えてください。

| プリセット | 使うとき | 値 |
|---|---|---|
| 縄跳びの縄 | 縄にキーがない（持ち手をコンストレインしただけ） | 硬さ 0、減衰 20、重さ 50、重力 100、落ち着かせてから開始 |
| 縄跳びの縄（キーに合わせる） | 縄にもキーがあり、回すタイミング（足の下を通る瞬間など）をキーに合わせたい | 硬さ 75、減衰 10、重さ 50、重力 100、アニメーションから開始 |
| 縄跳びの縄（手に合わせて回す） | 縄にキーがなく、手の回転に合わせて確実に回したい | 硬さ 85、減衰 20、重さ 50、重力 100、落ち着かせてから開始、手の回転に合わせて回す |

**手の回転に合わせて回す（縄跳び）**：縄にキーがなく手だけが動いているとき、物理（遠心力）だけで回すと、手の動きや床・体への当たり方しだいで
回ったり回らなかったりします。このチェックをオンにすると、縄が手に合わせて回ります。
- 両手の中点が描く円（中心は前後 0.5 秒の平均の位置）から、回す角度をフレームごとに読み取ります。
- 両手の間を軸に、その角度の向きにふくらんだ弓形（縄の長さと両手の距離から決まる円弧）を、縄の戻る先にします。硬さでそこへ引っぱり、
  遅れ・しなり・当たりは今の縄の計算で付きます。床や体に当たっても、戻る先が回っているので回り続けます。
- 手が円を描いていないところ（回し始め・止めたところ。円の半径が縄の長さの 1〜3 % 未満）では、戻る先は真下に垂れた弓形に戻ります。
- **硬さは 75 以上**、長く速く回る縄ほど高く。前のキャラクターの縄（204 cm）では、手が 5.9 周回すあいだに、硬さ 60 で 4.8 周、75〜85 で 5.5〜5.8 周、90 で 5.96 周。
  しなりは、硬さのカーブで真ん中を少し下げて付けます。
- 手首を回す動き（半径 8 cm、1 秒に 1.5 回、縄 150 cm、4 秒）で：物理だけでは 0 周、このチェックと硬さ 60 で 5.9 周（手は 6 周）。毎回床を打っても同じ。


* 持ち手はアニメーション（手へのコンストレイン）のまま **動かしません**。揺らすのは間のコントローラーの **移動** だけで、回転はアニメーションのままです
  （「移動」「回転」の軸の設定は使いません。ベイクも移動のチャンネルだけに出力します）。
* **縄の長さ**：自動（0）では、開始フレームの形（持ち手と縄のコントローラーを順につないだ長さ）です。
  リグの縄の本当の長さと違うと、両手を広げてもピンと張りません（利用者のショットでは、開始の形が 204 cm、両手は最大 112 cm しか離れない）。
  スプライン IK の **カーブ**（またはルートの **ジョイント**、**IK ハンドル**）を選んで「縄の長さ」の **選択から** を押すと、その長さになります
  （カーブは変形前の元の形の長さ、ジョイントは骨の長さの合計）。数値を直接入れることもできます。
  **両手の間が縄の長さより離れると、縄はピンと張り、さらに離れるとすべての間隔を同じ割合で伸ばします**（スプライン IK の伸びと同じ）。
* **縄どうしの当たり（絡まない）**（初期値オン）：縄が自分自身を通り抜けて交差しないようにします。
  縄のコントローラーの間の区間どうし（隣どうしは除く）が、縄の太さの 2 倍か、いちばん短い区間の長さの 3 割の大きいほうより近づかないように押し離します。
  押し離す向きは、そのステップの始めに離れていた向きなので、速い縄が 1 ステップで通り抜けるのも止めます。
  両手が交差しながら回る動き（縄 200 cm、コントローラー 10 個）で、区間どうしの最小の距離：オフ 0.45〜0.95 cm（交差）→ オン 5.45 cm。
  前のキャラクターの縄の結果はほぼ変わりません（物理だけで回る回数 6.41 → 6.40 周）。
* **伸び**：縄自体の伸びやすさ。0 = 伸びない（手が引っ張ったときだけ伸びる）。目安は、ぶら下がったときに 25 で 3%、50 で 1 割、100 で 4 割。
* **縄にアニメーションがない**（持ち手をコンストしただけ）ときは、**硬さ 0**、詳細の **初期状態を「落ち着かせてから開始」** にします
  （開始フレームの縄が垂れていなくても、重力で垂れた形から始まります）。
* **硬さ**：縄のコントローラーを、アニメーションの位置へ戻す強さです。縄にもキーがあり、回している縄のタイミング（足の下を通る瞬間など）をキーに合わせたいときは **70〜80** くらいにします。
  0 だと、縄は手の動きと重力だけで振られます（回している途中で、アニメーションとのタイミングがずれていきます）。
  検証シーンでは、硬さ 75 で、縄がアニメーションから最大 18 cm ほど遅れて・しなって付いていきます。
* 当たりは縄のコントローラーの位置で判定します（球・カプセル・床、押し出す揺れもの）。コントローラーが床より上にあれば、その間のスプラインも床より上になります。
  床や体に当たると、めり込む向きの勢いを消し、表面に沿う滑りにはブレーキがかかります（床で跳ね返りません）。
* **縄のコントローラーが持ち手の子のリグ**（持ち手を回すと、縄が振り回される構造）では、持ち手の回転に引きずられた動きを除いて揺らします。
  硬さで戻る先は「持ち手の **位置** には付いていき、**向き** は開始フレームのまま」の位置です（縄のコントローラーのキーを、持ち手が回っていないものとして読みます）。
  結果はワールドの位置で決まり、ベイクでは持ち手の回転を打ち消すように移動のキーを打ちます。適用率 0 では、元のアニメーション（振り回された縄）のままです。
  持ち手の子かどうかは階層で見ます。子でなくても、持ち手から見た位置がほとんど変わらない（コンストレインなどで持ち手に付いて動く）コントローラーも同じに扱います。
  スクリプトエディタに、どのコントローラーをそう扱ったかが出ます。
* 縄は、キーの縄より鋭くは曲がりません（隣の隣の点との間を、キーの曲がり角と縄の長さから決まる距離より縮めない）。
  床で止まった縄の底が V 字に折れるのを防ぎます。開始フレームでキーの縄が床に入っているときも、縄の長さと曲がりを保ったまま床の上へ出します。
* **硬さのカーブ**：縄では、カーブの左（根元）が **持ち手**、右（先端）が **縄の真ん中**（開始の形で両手からいちばん遠いところ）です。
  左右の半分に同じようにかかります。例：右を下げると、持ち手の近くはキーに付いていき、真ん中ほど柔らかく遅れてしなります。
  平らなら今までと同じです。
* 「ばらつき」「カメラ合わせ（ワープ吸収）」「振り子の長さ」「先端の軸」は縄では使いません。

### 床（当たり判定）

「当たり判定」欄の **＋ 床** で、選んだノードに付いて動く **床** を作れます。床のノードの位置を通り、ローカル Y 軸を上向きとする **どこまでも広がる平面** として当たります。
高さや傾きは、作った床を移動・回転して合わせます（チャンネルボックスの「表示の大きさ」は見た目だけです）。
床は縄だけでなく、「つながって揺れる」「1 つずつ」でも使えます（チェーンは各段の先端が床より上に来るように、根元のまわりで回します）。

### 揺れもの同士の当たり（押し出す揺れもの）

ほかの揺れものの骨に、食い込まないようにできます（例：髪が襟や袖の骨を突き抜けない）。

1. 押される側の揺れもの（例：髪）を選び、設定の **当たり判定** の下の **押し出す揺れもの** を押します。
2. 出てくる一覧で、当たる相手の揺れもの（例：襟）にチェックを入れます（いくつでも選べます）。
3. 両方の揺れものにチェックを入れて、計算します。

* **片方向** です。押される側だけがよけ、選んだ側（押す側）は押し返されません。押す側を先に計算し、その **計算した結果の骨** を当たりにします。
* 当たりの太さ = 押す側の「太さ」＋押される側の「太さ」。
* 揺れもの同士の当たりは、骨の **線分どうし** で見ます（先端だけでなく、骨の途中で横切るのも止めます）。
  骨の根元のすぐ近く（骨の長さの 5% 以内）は押しません。生え際が相手の骨の上にあっても、浮きません。
* 押す側が「つながって揺れる」でチェーンが 2 本以上あるとき（袖・スカートなど）は、**隣り合うチェーンの同じ段どうしの間に布の面を張って**、
  面にも当てます（骨だけだと、骨と骨の隙間をすり抜けるため）。
  * 隣のチェーンの決め方は「横のつながり」と同じです（根元の位置から）。根元どうしが段の長さの 2 倍より離れているチェーンの間には張りません
    （左右の耳飾りのように、離れたものを 1 枚の布にしないため）。
  * 面を突き抜けてしまった骨は、直前までいた側（初めは、その骨の根元がある側）へ押し戻します（面の向こうへ抜けたままにしません）。
* **激しい動き**（1 フレームで大きく動かす、など）でも飛び越えないように、押し出す揺れものの骨や面が 1 フレームで大きく動くところ、
  押される骨が速く振られているところでは、内部ステップを自動で細かくします（1 回に動く量が、当たりの太さの半分を超えないように）。
  細かくするのはそのフレームだけなので、ふつうの動きの計算時間は変わりません。
  * フレームの間の当たりの位置は、骨の根元と同じ曲線で補間します。体ごと 1 フレームで大きく動かしたとき、
    体に付いた根元と当たり（袖など）がフレームの途中でずれて、根元だけ当たりの向こうへ出ることがなくなります。
* **貫通して見えるときの確かめ方**：
  * 計算のあと、「押し出す揺れもの」の下に、骨が当たりに食い込んだフレームが出ます
    （例：「食い込み：フレーム 37〜39（3 フレーム）／最大 1.20 cm（フレーム 38、G_hair3_ctl、面を貫通）」）。
    適用率を混ぜた最終の結果で測ります。フレームごとの値はスクリプトエディタに出ます。
    食い込みがあるときは、続けて **原因の見当** を出します：
    * 骨の根元（押せない所）が当たりの中にある → 根元を当たりから離すか、太さを小さくする。
    * 適用率が 100 未満、または回転の軸の一部がオフ → 押し出した分が、元のアニメーションと混ぜたときに戻る。
    * どれでもない → SIMFLOW が押し出しきれていない（骨と面に挟まれた、など）。フレームと揺れもの名を開発者に伝えてください。
  * **「食い込みなし」なのにメッシュが貫通して見える** ときは、骨は当たっていません。次を確認してください。
    * 「太さ」がメッシュの太さより細い（押す側の太さ = 押す側のメッシュの厚みの半分くらい、押される側も同じ）。
    * 布の面がない所：端のチェーンの外側、最後の段より下（裾）、チェーンとチェーンが離れすぎて面を張っていない所。
  * **当たりを表示** にチェックを入れると、SIMFLOW が使っている当たり（押す側の骨の円柱と、チェーンの間の布の面）を、
    半透明の赤で表示します（直前の計算の結果どおりに動きます）。当たる距離は、これに押される側の「太さ」を足した所です。
    表示は選べず、クリーンアップで消えます。
* 押される骨の **根元は押せません**（片方向のため）。押す側が根元を越えて動いてくる場合（袖が髪の生え際を横切るなど）は、
  髪は根元のある側に出ます。押す側の上の端より根元が上にある場合は、激しく振られると、端を回り込んで反対側へ出ることがあります
  （回り込みは、すり抜けではありません）。
* 押し出す揺れものに選んでいない組み合わせは、計算しません（その分は重くなりません）。
* 「当たり判定」がオンのときだけ使えます（オフにすると、選んだままでも当たりません）。
* お互いを押し出す設定（A が B を、B が A を押し出す。3 つ以上で輪になる場合も）は、計算するときにメッセージで知らせます。
* 押す側の揺れものにチェックを入れずに計算したときは、その揺れものの前回の計算結果を使います（同じフレーム範囲のときだけ）。
  結果がないときは、スクリプトエディタに警告を出して、その揺れものは当たりに使いません。
* 揺れものを削除すると、ほかの揺れものの「押し出す揺れもの」からも外れます。設定はシーンに保存されます。プリセットには含みません。
* 両方向（お互いに押し合う）は、まだありません。

確認用のシーンの G（体に付いた、2 cm 間隔で垂れる硬いチェーン 3 本のカーテンと、その 1.5 cm 後ろの、チェーンとチェーンの **隙間の真後ろ** に垂れる髪。
体が後ろへ急に動いて止まる）で、髪がカーテンの面より前に出た量を測りました。

### 硬さのカーブ（つながって揺れるとき・縄）

「つながって揺れる」のときは、**硬さ** スライダーの下に **硬さのカーブ** が出ます。Maya のテーパーカーブと同じように、
横が根元 → 先端、縦が「硬さスライダーの値に掛ける割合（上 = 100%）」です。各段の硬さ = 硬さスライダー × カーブの値 です。

* Maya のランプと同じ操作です。何もないところをクリックすると点を追加（押したままドラッグで位置を決める）、点をドラッグで移動（両端の点は上下だけ）、
  点を右クリックするか、選んで Delete キーで削除します（両端の点は消せません。カーブを触っているときの Delete キーは Maya のノードを消しません）。
* 選んだ点の値は **選んだ点** に数値で入力できます。**平らにする** で、根元から先端まで同じ硬さに戻ります。
* 縦線は各コントローラーの位置、白い点はその段に実際にかかる硬さです（段の位置はリストの順番で等間隔に割り当てます）。
* 例：生え際だけ硬く、先端に向かってストンと落とす → 硬さ 60〜90、カーブは根元 100% → 先端 0%。
  後ろへ水平に伸びたもの（袖など）で、硬さ 70・根元 100% → 先端 0% のとき、各段の真下からの角度は 72 / 51 / 20 / 4 / 0° になりました
  （硬さ 0 なら全段 0°、根元が張るほど生え際で形を保ちます）。
* カーブはプリセットに保存できます。カーブを持たないプリセット（標準のもの）を適用すると、カーブは平らに戻ります。
* 1 つずつのときは、カーブは使いません（硬さスライダーの値をそのまま使います）。

### プリセット

標準のプリセット（ソフト、弾む、重い、髪、垂れる（髪・袖）、ふわっと（軽い髪）、尻尾、アクセサリー）と、ユーザーが保存したプリセットを **適用** できます。適用先は、一覧で選んでいる揺れものです。
プリセットの横の **…** から、今の値をユーザーのプリセットとして保存したり、ユーザーのプリセットを削除したりできます（保存先は `<MAYA_APP_DIR>/simflow/presets.json`）。標準のプリセットは削除・上書きできません。
プリセットに入るのは、適用率・硬さ・硬さのカーブ・減衰・重さ・追従性・空気抵抗・重力（オン/オフ、強さ、方向）・振り子の長さ・初期状態です。移動・回転の軸の ON/OFF は入りません。

### プリロール

**プリロール** に N フレームを指定すると、開始フレームの N フレーム前から計算を始めます。ベイクするのは開始〜終了の範囲だけです。
プリロール区間の入力は 2 つから選べます。

* **アニメーションをそのまま使う**：Maya が評価した値を使います。区間にキーがない場合は、カーブの外挿（通常は最初のキーの値のまま）になります。
* **開始フレームの姿勢で静止**：区間のあいだ、開始フレームの姿勢で止まっているものとして計算します。重力で垂れた状態から始めたいときに使います。

## パラメータと物理量の対応

UI の %（0〜100）は物理量にそのまま代入せず、次のように変換しています（`solvers/spring_solver.py`）。

| UI | 内部値 |
|---|---|
| Stiffness | 固有振動数 `f = 0.1 Hz × 100^(s/100)`（0 = バネなし、50 = 1 Hz、100 = 10 Hz。質量 1 のとき）。`ω² = (2πf)² / m` |
| Mass | `m = 10^((M−50)/50)`（0.1〜10、50 = 1.0）。重いほど遅く揺れ、重力で大きく垂れます |
| Damping | 減衰比 `ζ = D/100`（100 = 臨界減衰）。ターゲットに対する相対速度に作用するので、等速運動では遅れが残りません |
| Follow | 毎ステップ、ターゲットの動きをこの割合だけそのまま引き継ぎます（100 = アニメーション由来の慣性なし。重力は効きます） |
| Strength | 最終結果を元アニメーション（0）からシミュレーション（100）へブレンドします |
| Gravity | 100 = 1 G（9.80665 m/s²、内部単位 cm に換算）。100 を超える値も設定できます |
| Pendulum Length | 支点から仮想の先端（Aim Axis 方向）までの距離。UI のリニア単位で表示します |

### Rotation の重力と振り子

コントローラーの rotate pivot を支点とし、Aim Axis 方向の距離 L に仮想質点を置いて計算します。

`α = ω²·log(q_t q⁻¹) − c·(ω − ω_t) + (r × (g − a_pivot)) / L²`

重力は、支点と先端の位置から求めたトルクとして与えています。Euler 角に加算する実装ではありません。
`a_pivot` は支点の加速度による慣性力で、回転のみを有効にしていても、親が移動すれば揺れが発生します。
テストで、自由振り子の周期が `2π√(L/g)` と 3% 以内で一致することを確認しています。

### Rest Pose

**レストポーズをキャプチャ** を押すと、現在フレームのローカル姿勢を記録します。「戻る姿勢」を「レストポーズ」にすると、
Spring は「記録した姿勢を、アニメーションしている親に乗せた姿勢」に戻ろうとします
（コントローラー自身のキーではなく、Rest Pose が重力とバネの基準になります）。
初期設定の「アニメーション」では、アニメーションの姿勢が基準になります。

## ベイク

* **Additive Layer（既定）**：SIMFLOW が作成したレイヤー（回転は By Component）に `最終値 − 元の値` を書き込みます。範囲外は start−1 / end+1 に置いた 0 キー（ステップ接線）で保護します。
* **Override Layer**：最終値を書き込みます。レイヤーの weight を範囲の前後で 0 / 1 / 1 / 0（ステップ）にキーし、範囲外では元のアニメーションを通します。
* **Overwrite Base**：確認ダイアログを出したうえでのみ実行します。元のカーブを複製してバックアップし、範囲外の値は start−1 / end+1 のガードキーで保護します。

共通の安全策は次のとおりです。

* 次のチャンネルを検出した場合は、何も変更せずに中断します。ロックされたチャンネル、lockNode、Constraint・Expression・Driven Key・pairBlend で制御されているチャンネル、ユーザーが作成した同名レイヤー。Reference 内のカーブへの Overwrite も同様です。
* 処理全体を 1 つの Undo チャンクとして扱い、失敗時はそのチャンクだけを Undo します。チャンク名を一意にしてあるので、無関係な直前の操作を巻き戻すことはありません。
* ベイク後は、全キーフレームと範囲外の 2 フレームでワールド行列を再評価し、許容誤差を超えた場合はロールバックします。
* 再ベイクでは、同じツール管理レイヤーを更新します。レイヤーは増えていきません。
* 再計算と再ベイクのときは SIMFLOW のレイヤーをミュートしてサンプリングするので、常に元のアニメーションから計算します。

## 既知の制約と代替案

1. **非一様スケールの親**：親が非一様スケールの場合、ワールド空間の剛体回転は rotate チャンネルだけでは表現できません（シアーが必要になるため）。SIMFLOW は Aim 軸の向きを正確に保ち、Aim 軸まわりのねじれだけを近似します。ずれの量はベイクレポートに表示されます。
   代替案：親空間で計算するモードを追加する（未実装）。
2. **軸ごとの Translate / Rotate の ON/OFF**：物理計算は 3 軸すべてで行い、無効な軸は出力時に元の値に戻します。そのため、軸を一部だけ無効にすると、物理的には完全に整合しない場合があります（レポートに偏差を表示します）。
3. **Aim Axis 方向の移動**：支点が Aim Axis と平行に動いても、トルクは発生しません（物理的に正しい挙動です）。揺れを出したい方向に合わせて Aim Axis を設定してください。
4. **Overwrite のバックアップ**：バックアップは接続されていない animCurve として保存します。Optimize Scene Size の「未使用のアニメーションカーブ削除」で消える可能性があります。安全性を優先する場合は、Additive Layer を使ってください。
5. **SIMFLOW レイヤーの上にユーザーレイヤーを追加した場合**：次回ベイク時の検証で不一致として検出し、ロールバックします。
6. **Sample Step が 2 以上の場合**：検証はキーを打ったフレームだけで行います（キーの間は補間されます）。
7. **チェーンの段数が多いと計算が遅くなります**：関節をまとめて解くため、段数の 2〜3 乗で時間が増えます（上の性能を参照）。
   20 段を超えるような長いチェーンは、いくつかに分けるか、Phase 3 の nHair を待ってください。
8. **ベイク済みの子を残して親だけ再ベイクすることはできません**：子のチャンネルは親の結果に対して解いてあるためです。子も有効にして一緒にベイクするか、先に子を元に戻してください（ツールが警告します）。
